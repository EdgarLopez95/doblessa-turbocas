# Instrucciones del agente — Turbocas

## Alcance

Puedes modificar únicamente esta carpeta `web/`. Lee antes `ESTADO.md` y, como referencia de solo lectura, `../Recursos/`.

## Fuentes obligatorias

- `../Recursos/auditoria-web-turbocas.md`
- `../Recursos/sistema-diseno-propuesto.md`
- `../Recursos/seo-propuesto.md`
- `../Recursos/guia-ux-ui-propuesta.md`
- `../Recursos/recursos-web/mapa-uso-seo-imagenes.md`

## Reglas

- Es un mockup estático: no crear backend, login, pagos, e-commerce ni envíos reales de formularios.
- No copiar la web antigua ni usar contenido inyectado/obsoleto.
- No borrar, mover o renombrar `../Recursos/`.
- Mantener rutas compatibles con la base `/doblessa-turbocas`.
- Ejecutar `npm run build` antes de cada entrega.
- Actualizar `ESTADO.md`, hacer un commit atómico y enviar a `main`.
